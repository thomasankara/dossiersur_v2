# SDD SaaS Template

Template de projet SaaS avec workflow Spec-Driven Development (SDD)
pour Claude Code.

## Quick Start
1. Créer un repo depuis ce template
2. `./bootstrap.sh`
3. Répondre aux questions
4. Ouvrir Claude Code et commencer à coder en SDD

## Prérequis
- Claude Code installé et configuré
- Config globale installée (~/.claude/CLAUDE.md + agents + MCPs)
- Node.js 20+
- Comptes : Supabase, Vercel, Stripe, PostHog

## Stack
Next.js 15 + TypeScript + shadcn/ui + Tailwind v4
+ Supabase + Stripe + PostHog + Vercel
